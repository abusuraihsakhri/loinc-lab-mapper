For terminology review, not direct clinical coding. Codes may distinguish specimen, method, units, and property; confirm these against the current official LOINC catalog before use. The bundled list is not exhaustive.

Processing is local after the Pyodide runtime and mapper source load. The runtime downloads from jsDelivr. Do not upload patient-identifiable records. No query or CSV data is deliberately transmitted by this application.
